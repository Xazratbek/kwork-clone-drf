KWORK CLONE FRONTEND UI/UX SPEC
Versiya: 1.0
Sana: 2026-06-13
Maqsad: frontendchiga Kwork.com asosiy ko'rinishlari va interactionlarini tushuntirish.

1. Umumiy vizual yo'nalish

Kwork UI marketplacesga xos: toza, oq fon, yashil action rang, compact header, katalogga urg'u, card grid, ko'p filterli listing. Dizayn dekorativ emas, transaction-first. Buyer tez topishi, narxni tez ko'rishi, sellerga ishonch signalini tez baholashi kerak.

UI kayfiyati:
- clean
- utilitarian
- marketplace/catalog focused
- responsive
- ko'p ma'lumotli, lekin tartibli

Dominant ranglar:
- background: #ffffff, #f6f7f8, #f0f2f5
- primary green: #04b70a yoki yaqin Kwork yashili
- text dark: #111827 / #222
- muted text: #6b7280
- border: #e5e7eb
- warning: #f59e0b
- danger: #dc2626
- blue/info: #2563eb

Typography:
- Sans-serif readable.
- H1 homepage/category katta, detail title medium-large.
- Card title 14-16px, narx 16-18px bold.
- Form labels 13-14px.

Spacing:
- Header compact.
- Main container max-width 1180-1240px.
- Grid gap 16-24px.
- Cards 4 columns desktop, 2 tablet, 1 mobile.
- Border radius 4-8px, ortiqcha rounded emas.

15. Responsive rules

Desktop >= 1024:
- Header full nav.
- Listing sidebar + grid.
- Detail page left main + right sticky sidebar.

Tablet 768-1023:
- Category nav scroll.
- Listing filters drawer.
- Grid 2 columns.
- Detail sidebar may remain but narrower or move under media.

Mobile < 768:
- Header compact.
- Search full width.
- Category nav horizontal scroll.
- Listing 1 column.
- Filters bottom sheet.
- Detail package table becomes package cards/tabs.
- Right sidebar content moves above overview or after media.
- Order page sidebar becomes collapsible summary.

16. Empty/loading/error states

Loading:
- Skeleton cards for kwork grid.
- Skeleton detail media/title.

Empty:
- No services: show "No kworks found" + clear filters.
- No orders: CTA browse catalog.
- No proposals: waiting illustration/text.

Error:
- Payment failed: retry and choose another method.
- Permission denied: clear message.
- Moderation rejected: show reason and edit button.

17. Accessibility

- Buttons real button elements.
- Form labels visible.
- Keyboard focus states.
- Image alt text.
- Color contrast OK.
- Package table accessible with row/column labels.
- Modals/drawers trap focus.

20. UI copy tone

Copy qisqa va action-oriented:
- "Order"
- "Contact this seller"
- "Submit for review"
- "Request revision"
- "Approve delivery"
- "Open dispute"
- "Pay with Click test"
- "Pay with Payme test"

Avoid long explanatory text inside UI. Help text only forms/modalsda.
