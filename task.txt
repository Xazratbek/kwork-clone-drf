Quyida har bir frontend sahifasi uchun kerakli backend endpointlar, viewlar va URL lar ko'rsatilgan.

========================================
1. AUTH (Autentifikatsiya)
========================================
Frontend sahifalar: /auth, /verify-email, /forgot-password
Already built frontend: ✅

Backend kerakli endpointlar:
- POST /api/auth/login/          → Token (access + refresh) + user qaytaradi
- POST /api/auth/signup/         → Token qaytaradi, emailga verify link yuboradi
- POST /api/auth/verify-email/   → { token } → email tasdiqlaydi
- POST /api/auth/resend-verification/ → { email } → qayta yuboradi
- GET  /api/auth/me/             → Current user ma'lumotlari
- POST /api/auth/become-seller/  → { display_name, bio } → seller profil yaratadi
- POST /api/auth/forgot-password/ → { email } → parol tiklash linki yuboradi
- POST /api/auth/reset-password/ → { token, password } → parolni yangilaydi
- PATCH /api/auth/profile/       → Profile ma'lumotlarini yangilaydi
- POST /api/auth/change-password/ → { current_password, new_password } → parolni o'zgartiradi
- GET  /api/auth/seller/<id>/    → Sotuvchi profili ma'lumotlari
- PATCH /api/auth/notification-preferences/ → Bildirishnoma sozlamalari

View: AuthViewSet, SellerProfileView, PasswordResetView
URL: apps/accounts/urls.py

========================================
UMUMIY TALABLAR
========================================

1. JWT Authentication:
   - POST /api/token/          → Token olish
   - POST /api/token/refresh/  → Token yangilash

2. CORS sozlamalari:
   - FRONTEND_URL = "http://localhost:3000"
   - CORS_ALLOWED_ORIGINS = ["http://localhost:3000"]

3. Media fayllar:
   - /media/kworks/        → Kwork rasmlari
   - /media/avatars/       → Foydalanuvchi rasmlari
   - /media/deliveries/    → Yetkazish fayllari
   - /media/order_requirements/ → Buyurtma fayllari

4. Pagination:
   - Barcha list endpointlari paginated bo'lishi kerak
   - Format: { count, next, previous, results }

5. Filtrlash:
   - /kworks/ → search, category, price_min, price_max, currency, page
   - /reviews/ → seller, rating

6. Serialization:
   - KworkSerializer: id, title, slug, description, price_minor, currency, delivery_days, image, status, seller(id, username), category(id, name)
   - OrderSerializer: id, title_snapshot, price_minor, currency, requirements, status, buyer_username, seller_username
   - ReviewSerializer: id, rating, comment, buyer_username, seller_username, created_at
